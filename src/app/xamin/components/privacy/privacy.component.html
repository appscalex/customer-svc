1. Overview & Scope

This Privacy Policy describes the policies and procedures of AppScaleX Inc. ("AppScaleX", "we", "us", or "our") regarding the collection, use, protection, and disclosure of personal and technical data when using our DevOps automation platform, APIs, web interfaces, and customer services (collectively, the "Service").

Key Principle: AppScaleX acts as a Data Processor with respect to customer application code and workload telemetry, and as a Data Controller solely for account administration and billing information.

2. Information We Collect

To provide high-reliability delivery automation, we collect the following categories of data:

  • Account & Identity Data: Full name, corporate email address, organization name, job title, and authentication credentials (including SSO/SAML tokens).
  • Operational Telemetry: Pipeline execution durations, error codes, build step outcomes, container image tags, and resource utilization metrics.
  • Billing & Financial Data: Transaction records and billing addresses processed via PCI-DSS Level 1 certified payment gateways. We never store raw payment card details.
  • Log Data & Diagnostics: Browser headers, IP addresses, session cookies, and user agent strings collected for fraud prevention and audit trails.

3. Customer Code & Secret Security

We recognize that customer software source code and cloud credentials represent your most critical intellectual property:

  • Zero Source Code Training: We never train general AI or machine learning models on customer source code, pull request diffs, or proprietary configurations.
  • Secret Vaults: API tokens, private SSH keys, and cloud credentials are encrypted at rest using AES-256 GCM envelope encryption with keys managed in isolated HSMs.
  • Automatic Log Masking: Sensitive credentials matching standard regex patterns (AWS keys, JWTs, OAuth tokens) are sanitized and masked before being persisted in execution logs.

4. How We Use Data

We process information strictly for legitimate commercial and technical purposes:

  • To orchestrate builds, tests, container packaging, and Kubernetes deployments as configured by users.
  • To calculate FinOps cloud spend analytics, rightsizing recommendations, and idle resource detection.
  • To correlate incident telemetry against deployment events to provide root-cause diagnostic assistance.
  • To enforce role-based access control (RBAC), multi-factor authentication, and compliance audit logging.
  • To transmit transactional notifications, security bulletins, and billing statements.

5. Data Storage & Security Controls

All data is hosted in Tier-4 enterprise-certified cloud infrastructure located in designated geographical regions (United States, European Union, and Asia-Pacific).

All network transit utilizes TLS 1.3 encryption. Data at rest is encrypted with AES-256. Access to production systems requires hardware-token MFA, strict VPN peering, and zero-trust authorization.

6. Third-Party Subprocessors

We partner with vetted infrastructure and platform providers under strict Data Protection Agreements (DPAs) that satisfy GDPR Article 28:

  • Cloud Infrastructure: Amazon Web Services (AWS), Google Cloud Platform (GCP).
  • Authentication: Keycloak, Okta, Auth0.
  • Communication: Twilio SendGrid, Slack API.

7. GDPR & Global Privacy Rights

Depending on your jurisdiction (including the EU/EEA, UK, and California), you possess statutory rights regarding your personal data:

  • Right to Access: Request a full copy of your personal data held by AppScaleX.
  • Right to Rectification: Update inaccurate account details directly in the user settings.
  • Right to Erasure ("Right to be Forgotten"): Request deletion of your personal account data upon workspace termination.
  • Right to Data Portability: Export pipeline YAML configurations, audit logs, and metrics in standard JSON format.

8. Data Retention & Deletion

We retain account records for the active duration of your subscription. Pipeline execution logs and audit trails are retained for 90 days by default (up to 365 days on Enterprise plans). Upon workspace cancellation, all customer credentials and cached build layers are permanently destroyed within 30 days.
